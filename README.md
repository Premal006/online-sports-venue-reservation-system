# Online Sports Venue Reservation System

An Online Sports Venue Reservation System developed using Django.

## 📌 Project Description

This project allows users to view sports venues and book them online.
It is designed to make sports venue reservation easier and more convenient.

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Bootstrap

## ⚽ Features

- User management
- Sports category management
- Turf/venue management
- Venue booking
- Payment management
- Review management
- Django Admin Panel
- Admin styling using Jazzmin

## 📂 Project Structure

- `ArenaBook` - Main Django application
- `Online_Sports_Management_System` - Django project configuration
- `manage.py` - Django project management file
- `requirements.txt` - Required Python packages
- `.gitignore` - Files excluded from Git
